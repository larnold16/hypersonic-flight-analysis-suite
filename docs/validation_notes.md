# Validation Notes

The project uses staged sanity checks and comparisons to improve confidence in the conceptual model trends.

## Included Validation Concepts

- Vacuum, drag-only, and full-aero trajectory comparisons in Stage 12.
- Atmosphere continuity checks.
- Energy behavior checks for simplified cases.
- Regression-style stage comparisons.
- Monte Carlo and Pareto studies for trend exploration.

## Interpretation Guidance

Validation here means the code is behaving consistently with simplified engineering expectations. It does not mean the results are flight-certified, CFD-validated, or correlated to flight-test data.

Use outputs to compare trends across assumptions, launch angles, body types, and uncertainty cases. Do not interpret the results as real-world vehicle performance predictions.
